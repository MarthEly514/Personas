# Personas.
A web application for generating custom people illustrations.

![Logo Personas](icons/logo.png)

## Where does the ides come from?
I made **Personas** to enable anyone to easily make their own custom character for various uses.

## Tech stack
**Personas** is mostly a frontend app

- **HTML**
- **CSS**
- **JavaScript**

## What to use Personas for?
You can use **Personas** for various cases such as *web illustrations*, *profile avatar*, *social media post*
